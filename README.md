# 学习进度本

> 目标进度管理单页应用 —— WorkBuddy 参考工作台「学习进度本」原版复刻。

## 功能特性

- **四大模块**：今日概览 / 进度看板 / 周报 / 我的
- **云端资料库**：三张线上表（目标 `goals`、打卡 `records`、复盘 `reviews`），发布时由平台自动建表并注入
- **离线优先同步**：localStorage 缓存 + `_dirty` 标记 + 墓碑删除 + 失败重试，读写不丢数据
- **响应式三档**：手机底部 Tab / 平板顶部导航 / 电脑左侧边栏
- **业务算法**：进度环、连续打卡（含休息日）、近 7 天推算建议量、注意力红/琥珀提示

## 使用方法

在支持 WorkBuddy 在线 Page 的环境（workbuddy.link）打开 `学习进度本.html` 即可。
数据通过 WorkBuddy 资料库云端存储，多端实时同步。

## 技术说明

- 纯单文件 HTML，CSS / JS 全部内联
- 零外部依赖，图标与图表均为内联 SVG
- 数据层兼容 `window.__SMART_PAGE__.database` 云端接口，并降级到本地缓存
